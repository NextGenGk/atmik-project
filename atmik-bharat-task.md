## **Assignment: Inventory CRUD and Barcode Management** 

<mark>Build a small web application with the following features:</mark> 

## **1. Inventory Management** 

- <mark>Create, view, update and delete inventory items.</mark> 

- <mark>Include: Item Name, SKU, Category, Price, Quantity and Storage Location.</mark> 

- <mark>SKU must be unique.</mark> 

- <mark>Price and quantity cannot be negative.</mark> 

- <mark>Provide search by item name or SKU.</mark> 

- <mark>Add pagination to the inventory list.</mark> 

- Request confirmation before deleting an item. 

## **2. Barcode Functionality** 

- <mark>Automatically generate a Code 128 barcode using the item’s SKU.</mark> 

- <mark>Display the barcode on the item details page.</mark> 

- <mark>Allow users to download or print the barcode.</mark> 

- <mark>Provide an input field for barcode scanning or manual entry.</mark> 

- <mark>Display the corresponding item when a barcode is entered.</mark> 

- <mark>Show an appropriate error if the barcode is invalid or not found.</mark> 

## **<mark>Technical requirements:</mark>**
